# 사이트관리센터

works.ainsonic.com은 사이트관리센터의 공개 진입 페이지입니다. 저장소와 진입 페이지는 공개이며 noindex,nofollow는 검색 미노출 요청일 뿐 접근제어가 아닙니다. 실제 관리 데이터는 연결된 Google Apps Script 웹앱의 나만 접근 설정으로 보호됩니다.

| 공식 명칭 | 주소 | 역할 |
|---|---|---|
| 아인소닉 홈페이지 | https://www.ainsonic.com | 회사 소개·서비스·배너·공지 |
| 프로오디오뉴스 | https://news.ainsonic.com | 제조사·수입사 소식 큐레이션 |
| 사이트관리센터 | https://works.ainsonic.com | 비공개 관리 화면 진입 |

## 데이터 흐름

- 사이트관리센터 열기 카드는 기존 관리 앱으로 연결합니다.
- 센터의 배너·회사 공지 → 아인소닉 홈페이지, 뉴스 공지 → 프로오디오뉴스.
- 제조사 뉴스 본문은 프로오디오뉴스 저장소가 관리하고 센터의 뉴스 피드가 읽어옵니다.
- 저장, GitHub 제출, 실제 배포 완료는 구분해서 확인합니다.
- 자동 발행·정기 재확인은 Apps Script 코드 배포와 트리거 설치 후 동작합니다. 이 문서만으로 활성화되지 않습니다.

기존 관리 앱 URL, CNAME, 시트/컬렉션 키는 유지합니다. 공개 사이트에 관리센터 내비게이션을 새로 노출하지 않습니다.
